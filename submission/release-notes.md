# BeatAPI Remote Plugin preparation

This revision adds a read-only inline result component for existing task and
stored-result tools: native media playback with observed dimensions, bounded
research tables, source links, unknown-value handling, and same-task refresh.
The component cannot start paid work or select another account.

The added generation ratio restrictions and confirmation requirements were
withdrawn on 2026-11-06 to preserve existing API compatibility. Existing model
rules remain unchanged. The creative case now uses one low-cost image task,
not a video-ratio acceptance check. Final submission evidence must come from
the saved hosted version, not the local component preview.

Prepare a portable remote MCP + Skill package while preserving the existing
plugin identity and local marketplace installations. The remote Skill uses the
host OAuth connection only; it does not require local software or key entry.

The remote Skill now covers social/web research, text and decision models,
image/video generation and media workflows through Search, Inspect and exposed
execution operations. Social data is read/research-only. The existing local
generic capability tools remain compatible.

Independent public execution schemas and fixed-reference bindings can be compiled
from the real gateway catalog. The dispatcher validates inputs and the next adapter
does not walk untrusted content. The owner has confirmed hosted ChatGPT connection
and tool invocation. This does not establish that every review case has passed.
Generic public execution, local uploads and administration are excluded.

Narrow the next public catalog to research and creation: exclude seven precise
messaging-link, device-registration, guest-credential and advertiser-session
references. Preserve public contacts and comment keyword analysis. The gateway
consumes the same generated catalog; original API-key and local integrations
remain unchanged. This source change is not a production deployment.

Reuse the BeatAPI brand mark for listing and composer icons, including the dark
composer variant. Validate actual PNG dimensions and sizes before packaging.
Include five positive and three negative review-case drafts using portal fields;
check their named tools against the pinned catalog. Cases remain unrun drafts
until recorded in the intended host. The media fixture is now an AI-generated,
unbranded demo bottle hosted on the verified BeatAPI CDN; the recording is pending.
Use the owner-confirmed Logiavox LLC business name in the remote package without
changing local host branding. The portal identity still requires verification.

Public packaging requires a real deployed OAuth endpoint and passes a read-only
discovery and SDK tool-inventory comparison before emitting a ZIP. The pinned
v2 catalog retains OAuth declarations in SDK-visible metadata and binds each
operation to its reference/schema hash. Missing tools, schema or policy drift
prevent packaging; OAuth-only diagnostics cannot bypass that check.
Independent review-case evidence, reviewer access, policy coverage and demo
remain incomplete. This preparation is not a
published release or a completed review submission.
