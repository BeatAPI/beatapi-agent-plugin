# BeatAPI Agent Plugin 0.4.0

Updated the local MCP and installable Skill against the current gateway API.
The plugin exposes capability Search/Inspect/Run and four Web tools, including
preview/field controls, free stored-result reads and research task polling.
Existing specialized media tools remain available. Models and prices are
discovered at runtime. Credentials stay in host settings or CLI keychain.

The marketplace ZIP includes local MCP. The separate portable Skills-only
preparation draft includes metadata, icons and license, and requires host MCP
tools. CLI 0.4.0 referenced by the synchronized Skill was unavailable on public
npm on 2026-10-07; fallback remains blocked until upstream releases agree.
It is not submission-ready; local-execution eligibility,
identity, policy coverage and country targeting remain unresolved. Hosted review
requires authorization, individually exposed tools and real review evidence.
